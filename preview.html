Dynamic Everything

Every UI element — navbar, tables, forms, alerts, reports — is configurable per tenant and per user.

🏢
Multi-Tenant Architecture
Shared DB with Row-Level Security, schema-per-tenant for enterprise, database-per-tenant for government. Every query scoped by tenant.
🌍
Multi-Country Compliance
GDPR, data residency routing, multi-currency, multi-language, RTL support. Country-specific tax and compliance rules.
🎨
White-Label Branding
Custom domain, logo, colors, CSS variables, email templates. Each tenant gets a fully branded experience.
📊
Dynamic Table Columns
Users configure table columns — order, width, visibility, sort. Preferences saved per user per page.
📝
JSON Schema Forms
Tenant admins add custom fields without code deployment. Forms rendered at runtime from JSON Schema definitions.
📡
Device Adapter Framework
Vendor-agnostic MQTT ingestion. Onboard any GPS vendor via JSON config — zero code changes required.
⚡
Real-Time Telemetry
MQTT → RabbitMQ → SignalR. Live device streams, tenant-isolated WebSocket groups, instant alerts.
🔐
Dynamic RBAC
Tenant-defined roles with granular permissions. Different users in the same company see different menus and data.
🔔
Configurable Alerts
Per-tenant, per-country alert thresholds. Email, SMS, push, WhatsApp notifications. Locale-aware templates.
